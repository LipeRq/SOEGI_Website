ある晩のログ

昼は現場、見積は事務所に戻ってから。3件の依頼を片付けた晩の記録です。同じ3件でも、終わる時刻が2時間ちがいます。

いつもの晩

19:30 → 22:00 [150m]
  1. 19:30
    去年の似た見積を、フォルダから探す
  2. 20:05
    1件目。単価を電卓で確かめる
  3. 20:50
    2件目。単価表が古く、仕入れ先に確認
  4. 21:30
    3件目をExcelで清書
  5. 22:00
    3件を送って、ようやく終わり

ミツミルを使った晩

19:30 → 20:00 [30m // -2h]
  1. 19:30
    依頼のメモと写真を、3件入れる
  2. 19:31
    下書きが3件そろう要確認 2行
  3. 19:45
    印の行を確かめて、金額を決める
  4. 19:58
    いつもの書式のPDFで、3件を書き出す
  5. 20:00
    終わり。残りの2時間は、自分の時間
SAVED_TIME // +120 MIN AVAILABLE 20:00 — 22:00 FREE

* 時刻と内容は、架空の事務所の例です。

MOD_01 // PARSE_COREINPUT: MULTI_SOURCE

メモを見積の行に並べる

メール、電話のメモ、手書きの写真。形はばらばらで大丈夫。品名・数量・単価の行にして、合計まで出します。

  • メール蛍光灯をLEDに替えたい
  • 電話のメモ20本くらい、来週中に
  • 手書きの写真天井の高さ…？

御見積書（下書き）

LED直管ランプ 40形48,000

照明器具の交換工事70,000

古い器具の撤去・処分12,000

高所作業要確認8,000

出張費5,000

合計（税込）157,300円

要確認の付いた行だけ見れば、仕上がり。

MOD_02 // AMBER_FLAGALERT

迷った行に印を付ける

読み取れなかった数字、いつもと違う単価には琥珀色の印。見るのは印の行だけ。

  • LED直管ランプ 40形20本
  • 高所作業要確認
  • 出張費一式
MOD_03 // PRICE_SYNCDIFF: 0

前回の単価と照らす

過去の見積と単価表を見て、同じ品名には同じ単価。値上げしたら、単価表を1か所直すだけ。

    オフ・固定

    オフ・固定

    対応していません
